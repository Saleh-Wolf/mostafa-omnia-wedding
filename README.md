# Mostafa & Omnia Wedding Invitation

دعوة زفاف تفاعلية جاهزة للنشر على GitHub Pages.

## النشر

1. أنشئ مستودعًا عامًا باسم `mostafa-omnia-wedding`.
2. ارفع كل الملفات الموجودة هنا إلى جذر المستودع.
3. افتح `Settings > Pages`.
4. اختر `Deploy from a branch`.
5. اختر `main` ثم `/(root)` واضغط Save.
6. رابط الدعوة سيكون:
   `https://USERNAME.github.io/mostafa-omnia-wedding/`

## معاينة واتساب

بعد معرفة اسم مستخدم GitHub، غيّر سطر `og:image` داخل `index.html` إلى رابط كامل:

`https://USERNAME.github.io/mostafa-omnia-wedding/assets/images/wedding-preview.jpg`
